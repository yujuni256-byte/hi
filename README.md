## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| WASD | WS로 앞뒤로 가고 SD로 방향전환을 해 장애물을 피한다 |
| 타자치기 | 선생님한테 걸려오는 전화는 예시 답압을 입력해 선생님의 독촉을 피한다 |

**사용 방법**

1. 앱 주소에 접속합니다.
2. html 코드를 복사합니다
3. 메모장에 들어가 붙여넣습니다
4. index.html라는 이름으로 저장합니다
5. 실행합니다

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구**:Gemini
- **처음에 AI에게 한 요청(프롬프트)**:
  > html 형식의 반응형 웹사이트를 만들고 싶어 추가 할 내용은 이후 프롬프트에서 설명할게
- **AI가 만든 결과에서 내가 고치거나 추가한 부분**: 1인칭 3D 게임으로 하고 1인칭 시점에 킥보드를 추가해줘
  - 선생님한테 전화가 오고 그 전화엔 예시 답안을 치면 넘어가게 해줘
  - 학교를 만들고 학교에 도착하면 게임 승리 문구가 뜨게 해줘
- **어려웠던 점과 해결한 방법**:
  - 미리보기가 계속 안되서 이전 버젼 코드로 다시 만들었다
